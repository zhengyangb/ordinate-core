## Design Context

### Users

Ordinate is for people who build and maintain structured financial, operational, and analytical models. They work in the editor repeatedly, compare dense tabular information, author formulas, and expect keyboard, pointer, file, and undo behavior to remain predictable under long sessions.

### Brand Personality

Precise, calm, and capable. The interface should inspire confidence through structural clarity and native-tool restraint rather than decoration or marketing-style presentation.

### Aesthetic Direction

A refined desktop productivity tool with a quiet, utilitarian surface. Table geometry is the primary visual system: rails, frozen headers, body cells, selections, and append controls must align exactly. Light and dark themes should both feel intentional. Avoid decorative cards, loud gradients, heavy glass effects, oversized typography, and controls that visually impersonate spreadsheet data.

### Design Principles

- Treat table geometry as a shared model, not a collection of overlapping visual patches.
- Keep document content and editor chrome visually distinct while deriving both from the same measured axes.
- Preserve context during scrolling, freezing, selection, editing, and structural changes without layout shift.
- Favor compact, discoverable controls and progressive disclosure for secondary actions.
- Use desktop-style interaction in both browser and native hosts: interface labels are not browser-selectable, and command controls use the arrow cursor rather than a link hand.
- Keep text selection in editors and explicitly copyable content (`.selectable-text`), hand cursors for actual links, and specialized cursors for resizing/filling. Preserve keyboard focus indicators and the grid's own range selection.
- Validate interaction and alignment across short, wide, headed, unheaded, pinned, and scrolled sheets before shipping.
