# Ordinate UI Design Guidelines

## Core Principles
- Keep the interface quiet, bright, and functional.
- Prefer structured controls over raw implementation syntax.
- Reuse one interaction language before inventing a new one.

## Surfaces
- Floating UI should read as one surface.
- Positioning wrappers should usually be visually invisible.
- Add borders only when they communicate a real boundary.

## States
- Use fill and contrast as the primary state signal.
- Keep hover neutral and understated.
- Use accent sparingly for active or selected states.

## Controls
- Ghost buttons stay visually quiet at rest.
- Menus should be compact and stable.
- Segmented controls should use soft filled selection, not aggressive outlines.

## Formula Bar
- The central field should feel like one calm pill-shaped input.
- Dense metadata should be progressively disclosed through buttons and menus.
